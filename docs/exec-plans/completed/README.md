# Completed execution plans

Archive shipped or deliberately abandoned execution plans here. Use a date and descriptive slug:

```text
YYYY-MM-DD-feature-name.md
```

Each archived plan should preserve:

- original objective and acceptance criteria;
- meaningful decisions and deviations;
- migration or compatibility notes;
- verification evidence;
- remaining follow-ups linked to `../tech-debt.md`;
- commit, tag, or release reference when available.

Do not rewrite an archived plan to describe a later design. Add a dated note or a new design document instead.
